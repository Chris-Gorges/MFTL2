This site embeds the full Doxygen manual — call graphs, caller graphs, #include dependency graphs and the annotated source browser — under /doxygen/. That content is copied in from build/docs/html, which does not exist yet. 

python3 build_docs.py     # generate build/docs/html
python3 build_mkdocs.py   # rebuild this site with the manual inside it

python3 build_mkdocs.py runs both steps in the right order, so the second command alone is enough from a clean tree.
